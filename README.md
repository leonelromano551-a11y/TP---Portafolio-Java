Estudiante: Romano Ricardo Leonel

Descripción
Maquetado web sencillo para estructurar y alinear tarjetas horizontales mediante HTML y CSS.

Tecnologías utilizadas
- React (con Vite)
- HTML5
- CSS3
- git y github

Este proyecto utiliza HTML y CSS, por lo que no requiere la instalación de dependencias.

## Ejecución local
1. Clona este repositorio en tu equipo.
2. Abre el archivo "index.html" en tu navegador.
